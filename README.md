# Adaptive Multi-Asset Trading Model
Multi-asset systematic trading research model with Python, backtesting, risk controls, and optional AI/ML components.

Python-based systematic trading research framework across crypto, equities, and futures with regime filters, risk controls, backtesting logic, optional LLM sentiment, and ML expectancy modeling.

## Overview

This project is a quantitative finance research framework designed to test systematic trading logic across multiple asset classes. It focuses on signal generation, risk controls, backtesting structure, data validation, and optional AI/ML components.

## Key Features

- Multi-asset universe covering crypto, equities, and futures
- Regime-aware signal generation
- ATR-based stop losses and trailing exits
- Drawdown and risk-budget controls
- Correlation filters across positions
- Price-data validation layer
- Backtesting and performance reporting
- Optional LLM sentiment layer
- Optional ML expectancy model

## Security

This repository does not include API keys, account credentials, trade logs, model state files, cached price data, or agent request/response logs. API credentials must be supplied locally through environment variables.

## Disclaimer

This project is for educational and research purposes only. It is not financial advice and should not be used for live trading without independent validation, paper trading, and risk review.
